# 생성한 개념 설명 그림

대화에서 만든 설명 그림을 2026년 11월 3일 학습 사이트에 추가했습니다. 내장 이미지 생성 도구로 제작한 개념 이해용 그림이며 실제 공항 배치나 공식 운항 도면을 나타내지 않습니다. 해당 주제의 원본 교육 그림과 근거 링크는 사이트에서 함께 확인할 수 있습니다.

| 파일 (`dist/assets/visual-english/`) | 설명 |
| --- | --- |
| `holding-example.png` | 항공기, FIX, OUTBOUND, INBOUND, ABEAM을 위에서 내려다본 체공 예시 |
| `runway-hold-example.png` | 같은 항공기의 활주로 밖 HOLD SHORT와 활주로 안 LINE UP AND WAIT를 비교한 3D 예시 |
| `lahso-example.png` | 착륙한 항공기가 교차 활주로 전 지정 지점에서 멈추는 LAHSO 및 LANDING ROLL·ALD 예시 |

활주로 그림은 마지막 수정본을 사용했습니다. 대기 위치 표지의 실선 두 줄·점선 두 줄을 구분하고, 비행기 전체가 정지 지점 이전에 있도록 표현했습니다. 이미지 원본은 PNG 1536 × 1024이며, 본문과 확대 보기에서 동일 파일을 사용합니다.
