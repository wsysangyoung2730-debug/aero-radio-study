# 항공영어 기출 선별 기록

사용자가 제공한 문제 PDF와 답안 PDF에서 2017년 이후 회차의 영어 120문항을 대조하고 112문항을 수록했다. 자료에는 전자문제집 CBT 표기가 있으며 제3자의 기출 복원·편집본이다. 공식 KCA 비공개 CBT 문제은행 전체나 최신 출제 보장을 의미하지 않는다.

## 반영 범위

- 항공과 무관한 일반영어 상식은 기본 문제은행에 넣지 않는다.
- 항공 규정·교신·안전 지문을 해석하는 문법·빈칸 문항은 항공영어 독해로 수록한다.
- 사용자의 “2017년부터 일반영어 상식 제외” 요청을 선별 기준으로 적용했다. 이 자료만으로 제도 변경 공고의 시행일 자체를 새로 검증했다고 주장하지 않는다.
- 과거 법령 문항은 별도 현행 근거 검증이 필요하므로 `past-exams.json`에는 영어만 수록한다. 법규 선별 문항은 `past-exam-law.json`에서 관리한다.

| 시험일 | 수록 문항 | 문제 PDF 페이지 | 답안표 PDF 페이지 |
| --- | ---: | --- | ---: |
| 2017-03-04 | 17 | 83, 84, 85 | 85 |
| 2018-03-10 | 20 | 88, 89, 90 | 90 |
| 2018-10-06 | 17 | 93, 94, 95 | 95 |
| 2019-10-12 | 20 | 99, 100 | 100 |
| 2022-10-08 | 19 | 104, 105 | 105 |
| 2023-03-11 | 19 | 109, 110 | 110 |

페이지는 파일의 첫 페이지를 1로 센 PDF 페이지다. `exam.page`는 문항 번호·질문이 시작되는 페이지이며, 다음 페이지로 이어지는 선택지는 함께 연결했다.

## 검증 방법

1. pypdf와 pdfplumber로 두 단 지면의 텍스트를 추출했다.
2. 이미지로 삽입된 지문은 관련 페이지를 렌더링하여 확인하고 직접 전사했다.
3. 모든 수록 문항의 정답 번호를 답안 PDF의 선택지 표시(❶~❹) 및 각 회차 마지막 51–70번 답안표와 대조했다.
4. 2017·2018·2019·2022·2023 영어 페이지와 2023 답안 페이지를 시각 검토했다.
5. 개념에 맞는 기존 `en-*` 단원에 연결하고 한국어 해설을 새로 작성했다.
6. 원본의 정답 번호는 바꾸지 않았다. 정답 판단에 영향을 주는 내부 모순이나 오래된 기술 설명은 수정해 기출처럼 제시하지 않고 제외했다.

## 전사 시 정리한 사항

- 줄바꿈과 두 단 지면·페이지 연결에서 생긴 띄어쓰기를 정리했다.
- `redar contact`, `A redder`, `recevied`, `What dose`, `show moving`, `thenty`, `Those who demonstrating`, `response form you` 같은 명백한 오탈자는 개념과 정답이 바뀌지 않는 범위에서 바로잡았다.
- 지문에서 밑줄로 지정한 대상은 `(밑줄 친 단어: ...)`로 적었다. 강세 위치 자체가 정답을 좌우하는 2023년 55번은 수록하지 않았다.
- 일반 숫자통화표의 ITU 확장 부호(TAY-RAH-TREE 등)와 항공 교신의 짧은 숫자 발음(TREE 등)을 해설에서 구분했다.
- ELT를 121.5/243 MHz로만 설명하는 문항은 현대 406 MHz 위성 조난체계와 혼동될 수 있어 제외했다. 비상 음성 주파수 121.5/243 MHz 자체를 묻는 2023년 59번은 다른 개념으로 수록했다.

두 원본 PDF는 `dist/assets/originals/` 아래에 보관하며 자료·개정 확인 화면에서 열 수 있다. 검토 기준일은 2026-11-04이다.
