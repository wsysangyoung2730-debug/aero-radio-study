# 기출 중심 CBT와 문항별 확인

2026-11-04 반영. 기본 문제 구성은 **기출 중심**이며 선택 과목 안에서 기출을 먼저 뽑고, 부족한 수는 개념 확인 문제로 채웁니다. 두 과목 혼합 연습은 가능한 범위에서 법규·영어를 균등하게 배정합니다.

- 답 선택 후 **이 문제 채점**을 누르면 답을 확정하고 정오답을 보여 줍니다.
- **해설 보기/접기**로 문제 아래 설명을 펼치거나 접습니다. 기출 문제는 문제·답안 PDF의 해당 쪽과 관련 개념으로 연결합니다.
- 채점한 답은 변경할 수 없습니다. 문제 이동과 새로고침 후에도 답안·채점·해설 상태를 복원합니다.
- 개별 채점은 전체 학습 기록에 합산하지 않습니다. 최종 답안 제출 또는 시간 만료 시 점수·오답 기록을 한 번 저장합니다.
- 기존 저장된 연습의 `revealed` 상태와 일반영어 과거 문항 ID는 유지합니다. 새 CBT와 단원 연습에서는 `examEligible:false` 문항을 제외합니다.

## 영어 범위

[KCA 공식 종목 안내](https://www.cq.or.kr/qh_quagm02_003.do)의 현재 영어 범위는 표준항공교통관제 영어의 기초지식, 항공교통관제 용어, 알파벳·숫자 음성통화표입니다. 독립적인 일반영어 상식·문법 문항을 제외했습니다. 2017년 기준은 사용자의 학습 범위 요청으로 반영했으며, 현행 종목 안내가 역사적 개정일 자체를 입증하는 자료는 아닙니다. 항공 상황을 설명하는 명확한 보통 영어(plain language)는 관련 개념으로 유지합니다.
